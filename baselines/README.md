# Baselines

Generated baseline reference documents for WotC-published content.

Each baseline version is immutable once published. New content versions bump the baseline version.

## Versioning

- `v0.9/` — Partial baseline (Tier A subclasses only, generated at M9)
- `v1.0/` — Full baseline (all 61 subclasses + monsters, generated at M10)

## Format

Each baseline directory contains:
- `metadata.json` — Engine version, rules version, date generated, run count
- `subclasses/` — Per-subclass JSON baseline documents
- `monsters/` — Per-monster JSON baseline documents (v1.0+)
